Settings Form UI Specification
A configuration form with clean, minimal styling for user input.

Use the Fluent-UI components

Layout Structure
Card container with subtle shadow and rounded corners
Section title at top (bold, dark text)
Vertical stack of labeled form fields
Field Types
Side-by-side text inputs - Two inputs on one row for related data

Left icon inside first field
Placeholder text in each
Single text input with validation - Full-width input

Left icon inside field
Green checkmark on right when valid
Text input with prefix label - Input with non-editable prefix

Static text prefix (e.g., URL base)
Editable portion follows
Validation checkmark
Rich text editor - Multi-line input with formatting

Optional hint text in label (parenthetical)
Style dropdown (Paragraph, Heading, etc.)
Toolbar: Bold (B), Italic (I), Underline (U), Link, Bulleted list
Text area below toolbar
Dropdown selector - Single-select with icon

Left icon inside field
Selected value displayed
Chevron on right indicating expandable
Visual Style
Inputs: Rounded corners, light gray border, white background
Icons: Light gray, positioned inside field on left
Validation: Green checkmark on right edge
Typography: Clean sans-serif, dark gray labels
Spacing: Consistent vertical gaps between fields
Container: White card with subtle drop shadow
States
Default: Gray border
Valid: Green checkmark appears
Focus: (not shown, typically blue border highlight)
Error: (not shown, typically red border + message)
